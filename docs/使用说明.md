# 使用说明

[首页](../README.md) · [服务器部署](服务端部署指南.md)

## 1. 连接服务器

打开设置，填写管理员提供的服务器地址和访问令牌，保存。IP 自签名服务器按[对应指南](IP自签名HTTPS部署.md)处理证书。

## 2. 共享与观看

1. 共享者选择屏幕或窗口，填写房间号，选择清晰度、帧率和声音。
2. 点击开始共享；点击“刷新列表”或按 F5 更新屏幕与窗口列表。
3. 观看者打开房间列表，进入房间；有房间口令时输入口令。
4. 观看端点击声音按钮静音，再次点击恢复；退出后重新进入仍保留当前选择。
5. 共享者停止共享后，房间关闭。

清晰度和帧率是采集上限；观看效果还受源窗口尺寸、网络和设备性能影响。目前不支持录制，Windows 通知默认关闭。

## 3. 选择声音

| 选项 | 采集内容 |
| --- | --- |
| 关闭 | 只共享画面 |
| 所选应用声音 | 所选窗口对应的应用及子进程 |
| 系统声音 | 所有应用的播放声音 |
| 麦克风 | 所选麦克风 |

应用声音仅用于单个窗口，需要 Windows 10 2004 或更新版本以及支持该接口的系统更新；不可用时客户端会提示。浏览器可能同时采集其他标签页声音。共享时避免在本机播放同一房间的声音，使用麦克风时建议戴耳机。

## 4. 聊天与弹幕

- 房间中可查看成员并发送文字消息，每条最多 500 字。
- 共享界面可直接开关透明弹幕，设置宽度和高度；设置中的开关可控制默认显示。
- 点“调整弹幕位置”拖动，再点“锁定”；Ctrl+Shift+F10 切换调整模式。
- 弹幕默认鼠标穿透、不抢焦点；游戏使用无边框全屏，无法保证覆盖独占全屏。

聊天只保留本次连接的最近 200 条消息，新成员不接收入房前的历史记录。升级聊天功能需同步更新服务端，观众退出并重新进入。

## 5. 查看日志

共享、观看、设置和托盘均可点击“日志”，查看、刷新、复制记录或打开日志目录。

日志记录模块检查、连接、共享、音频和窗口异常，自动遮蔽令牌、口令及聊天正文。单个文件约 2 MB 后创建新文件，旧日志保留；自行删除日志前先确认不再需要。

声音模块缺失时，使用完整新版客户端复测，并提供日志中的模块路径与失败记录；连接异常先查[服务端排障](服务端部署指南.md#troubleshooting)。
